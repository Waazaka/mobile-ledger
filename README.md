# 手机账本

独立、单用户、移动端优先的个人账本，Node.js 22.13+，仅使用 Node 内置模块。

## 启动

```powershell
cd 'D:\dhs\创业贷款\手机账本'
node server.mjs
```

首次启动会生成本地 `.env`（随机口令、会话密钥、模型密钥加密密钥），终端显示一次初始登录口令；口令之后可在 `.env` 查看/修改。保留 `.env` 并做好安全备份，否则重启后生成新密钥会无法解密已保存的服务商 API Key。`.env` 与 `data/` 已排除在 Git 外，绝不可提交。运行 `node test.mjs` 运行集成与核心逻辑测试。

打开 `http://localhost:3000`。局域网访问需同一 Wi-Fi 并允许防火墙；当前 HTTP 服务没有 TLS，不要端口转发或直接暴露公网。远程部署需 HTTPS、身份保护、安全文件权限、备份策略和限流；当前尚未部署。

账本存于本地 `data/ledger.json`。服务商 Key 使用 AES-GCM 加密，主密钥存于项目本地 `.env`。备份功能不导出服务商 Key；恢复需在原环境重新配置 Key。建议另行安全保存 `.env` 密钥及 JSON 备份，不能将账单/密钥推到公开仓库。

## 已实现

- 口令保护、账户/币种/期初余额和基准日期。
- 多个 OpenAI 兼容视觉模型配置；Key 服务端加密；连接测试、图片能力测试、截图识别、结果修订和人工确认。无 Key 可走明确标注的模拟流程。
- 同一图片哈希幂等；整数分精确金额；重复跨来源候选、人工确认同一/不同交易、退款关联与撤销。建议不会自动合并；已确认重复在报表按一笔计算。
- CSV 字段映射预览；一对一精确匹配、补漏/冲突报告；显式确认后只补入未匹配行；同一文件哈希幂等。
- 本月按发生月的消费/退款/净额/收入汇总；分币种展示；关联账户后估算资金/信用负债余额（仅反映已录交易，不等于银行余额/应还额）。
- JSON 备份/恢复；恢复前需要用户确认，保留现有模型配置，备份不包含密钥。

## 已知限制 / 尚待真实验收

- 没有用户 MiMo API Key 与真实脱敏截图：模型连通、图片能力、真实识别质量未验证。模型输出始终需人工预览确认。
- CSV 支持 UTF-8/GB18030、用户手动映射的逗号分隔、ISO 日期、单一金额列和手动选择币种；不自动适配银行/微信/支付宝/花呗专有格式、加密文件、Excel、多币种换算；需根据真实脱敏账单样本逐个适配，并确认完整账期。
- 匹配为保守候选规则，不是自动裁决；复杂商户别名、多币种换算、余额/信用卡账单完整核对、还款双边账户过账、退款超额等需继续完善/核实。还款/转账目前不自动生成双边账户变动。
- 本项目可在本机/局域网手动运行；尚无 HTTPS 公网部署和跨设备恢复演练。
