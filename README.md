# 手机账本 M1

独立、单用户的手机网页账本。Node.js 22.13+，仅用内置模块，无第三方依赖。

## 运行

```powershell
$env:LEDGER_PASSWORD='请设置一个强密码'
$env:LEDGER_SESSION_SECRET='至少32字节的随机秘密'
$env:LEDGER_KEY_SECRET='另一个至少32字节的随机秘密'
node server.mjs
```

打开 `http://localhost:3000`。手机访问需同一局域网并允许防火墙入站，当前版本没有 TLS，不能直接暴露公网；外网部署前须由 HTTPS 反向代理和身份保护。

数据保存在 `data/ledger.json`，服务端加密保存服务商密钥。只备份本地数据文件及妥善保管 `LEDGER_KEY_SECRET`；此 M1 尚无备份恢复流程。

## M1 功能

- 口令登录和会话保护；账户增删。
- 添加/编辑 OpenAI 兼容模型配置，密钥只发到服务端加密保存，脱敏显示；可移除密钥。
- 测试真实连接与图片能力；仅 HTTPS、自定义地址解析后拒绝本机/私网等 IP，并拒绝重定向。
- 上传一张图片调用指定视觉模型；支持无密钥模拟预览（明确为模拟）；修订字段后确认入账。
- 同一图片内容只创建一个导入批次；交易金额以整数分存储和累计。

## 验证限制

尚无 MiMo API Key/真实截图，本地模拟流程和确定性数据校验不等于真实识图验收。M2 跨渠道去重、退款关联、完整账单复核与外网部署不在本阶段。
